# NovaVault Crypto Website

A modern responsive static crypto portfolio/investment website starter.

## Included
- Modern landing page
- Responsive mobile layout
- Market cards
- Portfolio options
- FAQ
- Interactive demo dashboard
- No real-money payment/deposit functionality
- Illustrative portfolio and market values

## Run locally
Open `index.html` in a browser.

## Deploy free with Vercel
1. Create a GitHub repository.
2. Upload all files in this folder.
3. Import the repository into Vercel.
4. Deploy with the default settings.

## Important before using for real financial services
Replace demo values with a reputable market-data source, implement secure authentication/backend infrastructure, and obtain any licenses/registrations/consumer disclosures required for the jurisdictions in which the service operates. Do not advertise guaranteed returns.
