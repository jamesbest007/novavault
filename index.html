FAQ

Questions, answered

Is NovaVault a real investment service?

This starter project is a front-end demo. Real deposits, withdrawals, custody and investment services require a secure backend and applicable legal/compliance setup.

Are the prices and portfolio values real?

No. The values shown in this demo are illustrative. Connect a reputable market-data provider before publishing live data.

Can I host this for free?

Yes. This static version can be deployed on free hosting such as Vercel or GitHub Pages.
